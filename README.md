# Cascade League Seasons

This repository is the generated, static public archive for Cascade League seasons and generations.

Each generation includes its results gallery, viewport and full-page screenshots, and isolated functional views rendered with the competitors' validated stylesheets. The site contains no model prompts, raw submissions, judging workspaces, command logs, credentials, or private orchestration state.

The archive is generated from completed immutable runs. Do not edit generated files by hand.
